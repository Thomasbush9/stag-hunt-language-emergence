# Repository guidance

Prioritize making the experimental assumptions, observations, payoffs, and
episode dynamics inspectable. Avoid production infrastructure until the world
and research question have been validated.

## Agent skills

### Issue tracker

Issues are local Markdown files under `.scratch/`. See
`docs/agents/issue-tracker.md`.

### Triage labels

Use the default triage vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository. See `docs/agents/domain.md`.
