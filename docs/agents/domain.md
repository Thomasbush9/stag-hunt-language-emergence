# Domain docs

This is a single-context repository.

Before changing experiment or implementation semantics, read:

- `CONTEXT.md` for the project purpose, glossary, and experimental invariants.
- Relevant decisions under `docs/adr/`.

Use the glossary's terms in code, tests, issues, and documentation. If a proposed
change conflicts with an ADR, surface the conflict explicitly rather than
silently overriding the decision.
